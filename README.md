**Lantern Lane: Spot the Difference** — a complete spot-the-difference game set in a lantern-lit Japanese night market. Two illustrated panels (Original / Changed) sit side by side; seven small changes hide between them: a missing lantern, a recoloured sign, a swapped snack, a moved cat tail, and more. Click a difference on either picture to ring it on both, watch the remaining counter fall, use up to three hints, and beat your best time. All art is inline SVG drawn by code and all sound is WebAudio — no assets, no network, it plays offline in a desktop browser. Keyboard: H for hint, R to restart. The screenshots in `screenshots/` are real renders of the game, staged by its deterministic `?shot=start|play|end` modes.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
